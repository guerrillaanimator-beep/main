`CLAUDE.md` と `docs/spec_core.md` を読んで、仕様書 §12 の「土台（プロトタイプ）」を作る計画を立ててください。まだコードは書かないでください。

計画には次の4つを入れてください。

1. 仕様で分からない所、矛盾している所への質問
2. マイルストーンの分け方。それぞれについて「完成の条件」と「私がエディタで確かめる手順」
3. C++ のクラス構成と、データ（CSV）ファイルの一覧
4. 私がエディタでやる必要がある作業の一覧

マイルストーンは、たとえば次のような分け方を考えています。もっと良い分け方があれば提案してください。

- M1：走る・ジャンプ・速度段階・カメラ（FOV）・デバッグ表示
- M2：壁走り・縁につかまる・落下時のリスポーン
- M3：高速 QTE（トリガー・判定・連鎖・判定ごとの結果）
- M4：戦闘（斬り抜け・弾き・回避）
- M5：タイマー・即リトライ・トドメのテスト

計画を確認してから、M1 から順に実装をお願いします。
